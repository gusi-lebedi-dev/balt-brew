# Инструкция по работе с сайтом «Балтика Brew»

Эта инструкция предназначена для сотрудников, которые обновляют информацию на сайте. Для работы не нужны знания программирования.

## 1. Как войти в панель управления

1. Откройте в браузере адрес сайта и добавьте в конце `/wp-admin/`.
   Например: `https://адрес-сайта.ru/wp-admin/`.
2. Введите логин и пароль, которые выдал ответственный за сайт.
3. Нажмите **«Войти»**.

Не передавайте пароль посторонним и не сохраняйте его на чужом компьютере.

## 2. Главное правило работы

После любых изменений обязательно нажимайте синюю кнопку **«Обновить»** или **«Опубликовать»**. Без этого изменения не появятся на сайте.

После сохранения:

1. Откройте сайт в новой вкладке.
2. Обновите страницу сочетанием `Ctrl + F5`.
3. Проверьте результат на компьютере и телефоне.

Если результат выглядит неправильно, не продолжайте менять другие поля. Верните последнее изменение или обратитесь к специалисту.

## 3. Как редактировать главную страницу

1. В левом меню выберите **«Страницы»**.
2. Найдите страницу с пометкой **«Главная страница»** и откройте её.
3. Ниже основного редактора находится блок **«Редактирование главной страницы»**.
4. Выберите нужную вкладку: **«Первый экран»**, **«Ассортимент»**, **«О бренде»**, **«Блок новостей»**, **«Видео»** или **«Слово автора»**.
5. После редактирования нажмите **«Обновить»**.

В каждой вкладке есть переключатель **«Скрыть с главной страницы»**. Включайте его только тогда, когда весь раздел нужно полностью убрать с сайта. Содержимое при этом не удаляется.

### 3.1. Первый экран

Здесь находятся четыре видеофайла:

- **«Видео для компьютера: начало»** — короткое вступление;
- **«Видео для компьютера: повтор»** — видео, которое повторяется после вступления;
- **«Видео для телефона: начало»**;
- **«Видео для телефона: повтор»**.

Чтобы заменить видео:

1. Нажмите на текущее название файла или кнопку выбора файла.
2. Загрузите новый файл либо выберите его в библиотеке.
3. Нажмите **«Выбрать»**.
4. Замените обе связанные версии: начало и повтор.
5. Отдельно проверьте компьютерную и телефонную версии.

Используйте только подготовленные файлы `MP4` или `WebM`. Не загружайте случайное горизонтальное видео в поле для телефона: оно может сильно обрезаться.

### 3.2. Ассортимент

В поле **«Товары»** находится список карточек. Порядок карточек в админке совпадает с порядком товаров на сайте.

Чтобы изменить товар:

1. Нажмите на строку с названием товара — карточка раскроется.
2. Измените нужные поля:
   - **«Название»**;
   - **«Описание»**;
   - **«Алкоголь»**;
   - **«Плотность»**;
   - **«IBU»**;
   - **«Фон слайда»**;
   - **«Бутылка»**.
3. Нажмите **«Обновить»**.

Поле **«Тип анимации»** отвечает не за текст, а за внешний вид и движение бутылки. Не меняйте его без необходимости. Для нового товара обычно выбирайте **«Обычный»**.

Чтобы добавить товар, нажмите **«Добавить товар»** внизу списка. Чтобы изменить порядок, перетащите строку товара за область с номером строки.

Чтобы удалить товар, раскройте его строку и нажмите **«Удалить строку»**. Делайте это внимательно: после сохранения товар исчезнет с сайта.

Для поля **«Бутылка»** лучше использовать PNG-изображение без фона. Фон слайда и бутылку нужно проверять вместе на компьютере и телефоне.

### 3.3. Блок «О бренде»

В верхней части можно изменить:

- **«Заголовок блока»**;
- фон для компьютера — рекомендуется `1765 × 891 px`;
- фон для телефона — рекомендуется `460 × 560 px`.

Ниже находится список **«Вкладки блока»**.

У каждой вкладки есть:

- **«Скрыть вкладку»** — временно убирает вкладку, но сохраняет её содержимое;
- **«Активная вкладка после загрузки»** — вкладка, которая будет открыта первой;
- **«Тип вкладки»**;
- **«Название вкладки»** — короткая надпись на кнопке;
- **«Заголовок текста»**;
- **«Текст вкладки»**.

Активной делайте только одну видимую вкладку. Если отметить несколько, сайт выберет первую.

Стандартные вкладки автоматически выводятся в таком порядке:

1. Концепция.
2. История.
3. Пивовары.
4. Пивоварни.
5. Дополнительные обычные вкладки.

#### Как редактировать историю и даты

1. Откройте вкладку с типом **«История с таймлайном»**.
2. Найдите поле **«События таймлайна»**.
3. Раскройте нужное событие.
4. Заполните:
   - год;
   - месяц;
   - заголовок события;
   - большой текст события.
5. Для новой даты нажмите **«Добавить событие»**.
6. Расположите события в нужном порядке перетаскиванием строк.

Поле **«Активное событие по умолчанию»** содержит номер события, которое будет открыто первым. Например, значение `1` означает первую дату, `2` — вторую.

### 3.4. Блок новостей на главной

На этой вкладке меняются только:

- название раздела;
- текст ссылки **«Все новости»**;
- фон для компьютера;
- фон для телефона.

Сами новости добавляются через отдельный раздел **«Новости»** в левом меню. На главной автоматически показываются три самые свежие опубликованные новости.

### 3.5. Видео

Здесь можно изменить:

- фон блока для компьютера — рекомендуется `1535 × 1024 px`;
- фон блока для телефона — рекомендуется `375 × 566 px`;
- название видео;
- ссылку на видео;
- описание.

В поле **«Ссылка на видео для iframe»** нужно вставлять только адрес плеера, а не весь HTML-код.

Правильный пример:

```text
https://vk.com/video_ext.php?oid=...&id=...&hash=...&hd=3
```

Неправильно:

```html
<iframe src="https://vk.com/video_ext.php?...">...</iframe>
```

Как получить ссылку VK:

1. Откройте видео в VK.
2. Нажмите **«Поделиться»** или **«Экспортировать»**.
3. Скопируйте код для вставки.
4. Из кода скопируйте только адрес внутри `src="..."`.
5. Вставьте этот адрес в поле сайта.

После замены обязательно проверьте воспроизведение на компьютере и настоящем телефоне. Если VK показывает сообщение **«Видео недоступно»**, не меняйте остальные настройки — передайте ссылку специалисту.

### 3.6. Слово автора

На этой вкладке меняются:

- название раздела;
- текст ссылки **«Все записи»**;
- фон для компьютера;
- фон для телефона.

Публикации добавляются через обычный раздел WordPress **«Записи»**. На главной автоматически показываются три самые свежие опубликованные записи.

Поля **«Заголовок»** и **«Текст»** в настройках главной используются только тогда, когда нет ни одной опубликованной записи.

## 4. Как добавить новость

1. В левом меню выберите **«Новости»**.
2. Нажмите **«Добавить новость»**.
3. Введите заголовок.
4. В большом редакторе добавьте полный текст новости.
5. Добавьте **«Отрывок»** — короткое описание для карточки на главной. Если поле не видно, откройте настройки редактора и включите панель **«Отрывок»**.
6. Установите **«Изображение новости»**. Оно будет показано в карточке и на странице новости.
7. Проверьте дату публикации. Самые новые материалы показываются первыми.
8. Нажмите **«Опубликовать»**.

При первой публикации WordPress может попросить подтверждение. В таком случае ещё раз нажмите **«Опубликовать»**.

На главной показываются до трёх последних новостей. На странице **«Все новости»** показываются все опубликованные новости, по девять карточек на странице.

Чтобы временно убрать новость с сайта, измените её статус с **«Опубликовано»** на **«Черновик»**. Необязательно удалять материал.

Чтобы изменить существующую новость, откройте **«Новости»**, нажмите на её заголовок, внесите изменения и нажмите **«Обновить»**.

## 5. Как добавить запись в раздел «Слово автора»

1. В левом меню выберите **«Записи»**.
2. Нажмите **«Добавить новую»**.
3. Введите заголовок.
4. Добавьте полный текст.
5. Заполните короткий **«Отрывок»** для карточки.
6. Установите **«Изображение записи»**.
7. Проверьте дату.
8. Нажмите **«Опубликовать»**.

На главной показываются до трёх последних записей. Все опубликованные записи доступны по ссылке **«Все записи»**.

Чтобы изменить существующий материал, откройте **«Записи»**, нажмите на его заголовок, внесите изменения и нажмите **«Обновить»**. Чтобы временно скрыть материал, переведите его в черновики.

## 6. Как изменить футер, телефон и документы

1. В левом меню выберите **«Футер»**.
2. Измените нужное поле.
3. Нажмите **«Обновить»** или **«Сохранить изменения»** внизу страницы.

В этом разделе находятся:

- логотип футера;
- ссылка на VK;
- телефон, который видит посетитель;
- телефон для ссылки;
- подпись под телефоном;
- юридическое название компании;
- название кнопки обратной связи;
- PDF с правилами обработки персональных данных;
- PDF об использовании cookie;
- текст и кнопка cookie-баннера.

Поле **«Телефон для ссылки»** заполняется без пробелов и скобок. Пример: `+78007002880`.

Заявки из формы обратной связи отправляются на адрес `bsite.robot@dialogforce.tech`. Через админку этот адрес не меняется. Для его замены обратитесь к специалисту.

Если вы изменили текст cookie-баннера, но баннер не появился повторно, откройте сайт в режиме инкогнито. Браузер запоминает, что пользователь уже нажал кнопку принятия.

## 7. Работа с изображениями и файлами

Перед загрузкой проверьте файл:

- изображение должно быть чётким;
- не используйте фотографии прямо с телефона размером в десятки мегабайт;
- для фотографий подходят JPG или WebP;
- для картинок с прозрачностью подходит PNG;
- документы должны быть в PDF;
- видео — MP4 или WebM;
- не загружайте файлы с непонятными названиями вроде `image123-final-final2`.

Чтобы заменить изображение:

1. Нажмите на текущее изображение или кнопку **«Добавить изображение»**.
2. Выберите файл из библиотеки либо откройте вкладку загрузки файлов.
3. Загрузите файл.
4. Нажмите **«Выбрать»**.
5. Сохраните страницу.

Удаление изображения из поля не удаляет сам файл из библиотеки. Не удаляйте файлы через раздел **«Медиафайлы»**, если не уверены, что они больше нигде не используются.

## 8. Что заказчику лучше не менять

Без согласования со специалистом не открывайте и не меняйте:

- **«Внешний вид»**;
- **«Плагины»**;
- **«Настройки»**;
- **«Инструменты»**;
- настройки постоянных ссылок;
- тему сайта;
- код страниц;
- пользователей и их роли.

Не вставляйте в текст JavaScript, iframe-коды и случайный HTML. Исключение — поле ссылки на видео, куда всё равно вставляется только адрес `src`.

## 9. Проверка перед завершением работы

Перед выходом из админки убедитесь:

- изменения сохранены;
- заголовки не слишком длинные;
- в тексте нет опечаток;
- изображения загрузились;
- карточки не остались без короткого описания;
- дата публикации правильная;
- главная страница проверена на компьютере;
- главная страница проверена на телефоне;
- ссылки, PDF и видео открываются.

## 10. Если что-то пошло не так

### Изменения не появились

1. Проверьте, нажата ли кнопка **«Обновить»**.
2. Обновите сайт через `Ctrl + F5`.
3. Откройте страницу в режиме инкогнито.

### Раздел пропал с главной

Проверьте переключатель **«Скрыть с главной страницы»** в настройках этого раздела.

### Новость или запись не показывается

Проверьте статус материала. Он должен быть **«Опубликовано»**, а дата публикации не должна находиться в будущем.

### На карточке слишком много текста

Заполните поле **«Отрывок»** коротким текстом из одного–трёх предложений.

### После изменения изображений сломалась композиция

Верните прежнее изображение и сообщите специалисту, какое изображение нужно установить. Не пытайтесь исправлять размеры через настройки темы или код.

### Не работает видео

Проверьте, что в поле вставлена ссылка вида `video_ext.php`, а не обычная ссылка на страницу VK и не весь код `<iframe>`. Если ссылка правильная, передайте её специалисту.
